## HTML

JavaScript와 CSS 등과 함께 웹 페이지를 구성하는 언어.

### 태그

태그는 여는 태그와 닫는 태그로 이루어져 있다.

`<태그이름>내용</태그이름>` / 대소문자 구분 X

| 태그 | 설명 | 사용 예시 |
| --- | --- | --- |
| `<h1>` | 제목 표시 | `<h1>Title of the document~</h1>` |
| `<p>` | 문단 표시 | `<p>This is the first paragraph.</p>` |
| `<strong>` | 텍스트를 굵게 강조 | `<strong>Text to be emphasized.</strong>` |
| `<a>` | 다른 페이지나 URL로 이동하는 하이퍼링크 생성 | `<a href="https://dreamhack.io">Go to the Dreamhack website</a>` |
| `<img>` | 이미지 삽입. 닫는 태그 불필요 | `<img src="dreamhack_logo.jpg">` |
| `<button>` | 클릭 가능한 버튼 생성 | `<button type="button">Click here.</button>` |

#### 속성(Attribute)

`<태그이름 키1="값1" 키2="값2" 키3="값3">내용</태그이름>`

```html
<a href="https://www.example.com" target="_blank">Go to the example website</a>
```

### 구조

```html
<!DOCTYPE html> <!-- 문서의 유형을 알려주는 선언문 -->
<html> <!-- html 문서의 시작 태그 -->
<head> <!-- Metadata를 작성하는 부분(데이터에 대한 설명 데이터) -->
  <title>My First Page</title>
</head>
<body> <!-- 본문 내용이 들어가는 부분 -->
  <h1>Welcome to HTML!</h1>
  <p>Hello, World!</p>
</body>
</html>
```

## Flask

Python 기반으로 하는 웹 프레임워크로, 파이썬의 모듈 형태로 제공된다.

#### 실습: `/simple_page` 경로 요청 시 HTML 문서 반환하기

```python
from flask import Flask, render_template          # Flask 웹 프레임워크 모듈을 불러옵니다.

app = Flask(__name__)

@app.route('/simple_page')                        # /simple_page 경로로의 요청이 들어오면,
def get_simple_page():                            # get_simple_page()를 실행합니다.
    return render_template('simple_page.html')    # HTML 문서인 simple_page.html을 반환합니다.

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=31337)           # 웹 서버를 구동합니다.
```

Flask를 통해 `app.py`라는 Python 소스 코드 파일을 만들었다. 이 코드는 `/simple_page` 경로로 요청을 보내면 간단한 웹 페이지를 반환하는 알고리즘이다.

### 템플릿 렌더링

Flask에서 `render_template()`를 사용해서 템플릿 렌더링을 할 수 있다. 서버의 Python 코드에서 생성한 변수나 값을 뼈대인 HTML 코드에 삽입하여 최종 HTML 문서를 만드는 과정을 말한다.

```diff
+import datetime
 from flask import Flask, render_template

 app = Flask(__name__)

 @app.route('/simple_page')
 def get_simple_page():
-    return render_template('simple_page.html')
+    dt = datetime.datetime.now().strftime('%Y-%m-%d %H:%M:%S')
+    return render_template('simple_page.html', current_time=dt)

 if __name__ == '__main__':
     app.run(host='0.0.0.0', port=31337)
```

`dt`는 현재 시각을 문자열 형태로 반환받는다. 그리고 `dt`를 `current_time`이라는 변수로 `render_template`을 이용해 반환한다.

{% raw %}
```diff
 <!DOCTYPE html>
 <html>
 <head>
   <title>My Simple Web Page</title>
 </head>
 <body>
   <h1>Explore the World of HTML!</h1>
   <p>Greetings from the Web!</p>
+  <h2>{{ current_time }}</h2>
 </body>
 </html>
```
{% endraw %}

아래와 같은 형식으로 HTML 코드를 작성하면 된다.

{% raw %}
1. `{{ 표현식 }}` → `{{ current_time }}`
2. `{% 구문 %}` → `{% if 조건문 %}`, `{% for x in range(n) %}`
3. `{% 상속문 %}` → `{% block 블록명 %}` `{% endblock %}`, `{% extends '부모템플릿파일이름' %}`
4. `{# 주석 #}`
{% endraw %}

### 사용자로부터 입력 받기

1. URL 경로 매개변수를 통한 입력 처리

```python
from flask import Flask, render_template

app = Flask(__name__)

@app.route('/welcome/<name>')  # URL을 통해 name 변수를 입력 받는다.
def get_welcome_name(name):
    return render_template('result.html', name=name)

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=31337)
```

`http://127.0.0.1:31337/welcome/이름` 와 같이 URL에 입력 시 `이름`을 `name`에 초기화한다.

2. URL 쿼리 매개변수를 통한 입력 처리

`?` 뒤에 오는 매개변수로 데이터를 전달한다.

```text
http://example.com/search?query=flask&page=2
```

`query`는 매개변수 Key를 나타내며 `flask`가 매개변수 Value를 나타낸다. `&`를 통해 또 다른 Key-Value를 입력받을 수 있다.

_쿼리 문자열로 전달한 `user_name` 값이 페이지에 출력된 모습_

{:start="3"}
3. `<form>` 태그를 통한 POST 데이터 입력 처리

`<form>` 태그는 웹페이지에 이용자가 입력할 수 있는 양식을 만든다.

| 속성 | 설명 |
| --- | --- |
| `action` | 입력 값을 전송할 URL을 지정 |
| `method` | 입력 값을 전송할 HTTP 메시지의 메서드를 설정 (GET, POST) |
| `type` | 입력 필드의 유형<br>1. text<br>2. number<br>3. password / 입력 값이 `*`로 표시된다. |
| `name` | 서버로 전송될 때 데이터 Key를 설정한다. |
| `id` | 입력 폼의 고유 식별자이다. |

```html
<!DOCTYPE html>
<html>
<head>
  <title>Form Exercise</title>
</head>
<body>
  <h1>Form Exercise</h1>
  <!-- 여기가 핵심 -->
  <form action="/submit" method="post">
    Name:
    <input type="text" id="username" name="username">
    <button>Submit</button>
  </form>
  <!-- -->
</body>
</html>
```

![Form Exercise 페이지의 입력창에 dreamhack을 입력한 화면](</assets/img/2026-08-05-Xpert(5)/06.png>)
_`<form>` 태그로 만든 입력 양식_

이렇게 입력받은 데이터는 `request.form`에 저장되고 `.get()` 메소드를 이용해서 가져올 수 있다.

```python
from flask import Flask, render_template, request

app = Flask(__name__)

@app.route('/login', methods=['POST'])
def post():
    username = request.form.get('username')
    return render_template('index.html', username=username)

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=31337)
```

## LM을 이용한 웹사이트 만들어보기

> 아이디어: HTML 코드를 작성하는 LM을 가져와서 직접 HTML 문서를 반환하게 만들어보면 어떨까?
{: .prompt-tip }

```python
!pip install bitsandbytes flask-cloudflared -q

from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig
from flask import Flask, request
from flask_cloudflared import run_with_cloudflared
import torch

MODEL = "Qwen/Qwen2.5-Coder-7B-Instruct"

bnb = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.float16,
)

tokenizer = AutoTokenizer.from_pretrained(MODEL)
model = AutoModelForCausalLM.from_pretrained(
    MODEL,
    quantization_config=bnb,
    device_map="auto",
)

app = Flask(__name__)
run_with_cloudflared(app)

def generate_html(user_input):
    messages = [
        {"role": "system", "content": "Output only a complete HTML document. Put CSS in a <style> tag. Never write explanations or greetings."},
        {"role": "user", "content": user_input},
    ]
    text = tokenizer.apply_chat_template(messages, add_generation_prompt=True, tokenize=False)
    text += "<!DOCTYPE html>"  # 시작 단어를 설정해줌
    inputs = tokenizer(text, return_tensors="pt").to(model.device)
    outputs = model.generate(
        **inputs, max_new_tokens=2048, do_sample=False,
        pad_token_id=tokenizer.eos_token_id,
    )
    result = "<!DOCTYPE html>" + tokenizer.decode(
        outputs[0][inputs["input_ids"].shape[-1]:], skip_special_tokens=True
    )
    with open("result.html", "w", encoding="utf-8") as f:
        f.write(result)
    return result

@app.route('/')
def index():  # 기본 페이지는 index.html -> 사용자의 입력을 받아서 user_input으로 반환
    return render_template('index.html')

@app.route('/submit', methods=['POST'])
def submit():  # user_input 토대로 만들어진 html을 보낸다.
    user_input = request.form.get('user_input')
    return generate_html(user_input)

app.run()
```
